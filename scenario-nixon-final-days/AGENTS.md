# AGENTS.md - “尼克松最后时日”场景约定

本文件适用于本场景包及其全部子目录，并在仓库根目录 `AGENTS.md` 基础上追加约束。字段定义以 `../docs/scenario-schema.md` 为准。

## 场景边界

- 本场景固定为一个会场、四名代表，由亨利·基辛格担任主席，开场阶段为有主持核心磋商；
- 场景切入点为 1974 年 8 月 7 日晚，尼克松尚未宣布辞职；不得把 8 月 8 日之后的结果写成角色已知事实；
- 尼克松不设为代表 Agent，其来电、指示与状态变化只能作为外部事件或运行时信息出现；
- 场景只保存声明式历史内容，不实现专属 Python 机制。

## 历史与玩法口径

- “国防部长要求异常军事指令先回到本人和正规指挥链复核”有回忆、报道及后续研究支持，但具体措辞、覆盖范围与是否专指核命令存在争议；不得写成无争议且已经合法生效的正式命令；
- 关于尼克松饮酒、情绪和行为的材料应写成同期人物的担忧或后来的叙述，不作医学诊断；
- 华约异常动向、白宫越级询问和本次四人密会均为服务玩法的架空情报，不得冒充真实档案事件；
- “软政变”是玩家可能作出的政治评价，不是场景预设结论。

## 信息边界与验证

- 核指挥顾虑、私下交接准备和各角色底线只能放在对应角色卡的 `private` 区块；
- `background.md` 只给出四人共同获知的制度约束与开场简报；
- `mechanism.py` 必须保持 0 字节，不得创建 `mechanism.yaml`；
- 修改后至少验证 YAML 可解析、四个席位与角色文件一一对应、主席引用有效、议程和关系 ID 一致，并用通用加载器成功加载场景。
